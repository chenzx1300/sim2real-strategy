0. 战略定位

0.1 行业痛点

塑料注塑行业目前是 "经验驱动 + 试错迭代" 模式：

  • 工程师凭经验调工艺 → 试模 → 看结果 → 改参数 → 再试模
  • 一个新零件的开发周期：3-6 个月
  • 单次试模成本：¥5,000-50,000
  • 知识沉淀：老师傅脑子里，新人无法继承
  • 行业研究范式：年周期（博士论文级别），与生产脱节

0.2 我们的目标 — 新研究范式

AI-Augmented Process Engineering：把"仿真 + AI + 历史数据 + 实时优化"做成一个闭环工作流，让工程师从"试错"变成"决策"，让研究员从"年周期"变成"月/周周期"。

维度传统范式新范式
周期季度/年级别周/月级别
依赖老师傅经验数据 + 模型 + 经验协同
研究产出论文论文 + 可落地的 AI 工具
决策经验直觉AI 建议 + 人工审核
知识沉淀文档/培训可复用 AI 模型 + 训练数据

0.3 项目战略价值

维度价值
技术工艺级别 sim2real 国内空白（PINN + 注塑交叉）
学术可投顶会/顶刊（Nature MI / JMP / Composites）
商业可孵化 SaaS（CAE-AI Service）
组织重构研究院工艺所工作流
